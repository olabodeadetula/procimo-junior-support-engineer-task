# Procimo Tech – Junior Support Engineer Technical Challenge

**Candidate:** Olabode Adetula

## Overview

This repository contains my submission for the Junior Support Engineer technical challenge at Procimo Tech, prepared as part of the recruitment process.

The exercise shows my approach to technical support triage, troubleshooting, knowledge-base documentation, bug reporting and technical escalation.

## What the document covers

- **Task 1:** ticket analysis and triage
- **Task 2:** documentation validation
- **Task 3:** bug report and test cases
- **Task 4:** internal communication
- **Task 5 (optional):** reading tag status data and a SQL query

The scenarios and product details come from the exercise brief and are illustrative, not descriptions of Procimo's real systems.

## Approach

I focus on assessing the impact and urgency of each issue, identifying what information is missing before drawing conclusions, and recommending practical next steps.

When an issue needs escalation, I aim to communicate findings clearly, document the evidence and assumptions, and give the receiving team actionable information.

AI tools were used as permitted by the challenge instructions, to help draft and to check clarity and consistency. I reviewed the results, decided which suggestions to keep, added my own points, and take responsibility for the final submission.
